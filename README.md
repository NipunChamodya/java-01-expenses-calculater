# Java 01: Expense Calculator

A simple command-line application built in Java that calculates total monthly expenses and remaining balance based on user input.

## Concepts Learned
* Variables and Reassignment
* Primitive Data Types (`int`, `double`, `String`, `boolean`)
* Mathematical Operators
* Reading user input using `java.util.Scanner`

## How to Run
1. Open the project in an IDE (like IntelliJ IDEA).
2. Run the `Main.java` file.
3. Enter your monthly income and expenses when prompted in the console.
